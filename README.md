# Filesystem-VMFS6

Native single-extent VMFS6 geometry, LVM UUID, 8192-byte FDC bitmap and descriptor validation. Genuine VMFS6 media remains unavailable; structural fixtures only.

Independent Common V2 development provider. Only CORE PROBE is exported. No namespace mounting, mutation, defragmentation, recovery or physical BOOT qualification is claimed. Unknown, incomplete and corrupt profiles are refused. Existing PDF-only release remains unchanged. Real VMFS6 media is required before even recognition can be independently qualified. The upstream fork's captured image is VMFS3, not VMFS6.
