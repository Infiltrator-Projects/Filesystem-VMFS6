# VMFS6 documentation installation

The documentation-only release owns exactly `/System/Resources/Documentation/Filesystem-VMFS6.pdf`. Its source-downloading RUN supports build-only and output options. The amd64 DEB owns the PDF; normal Debian removal removes it. No filesystem implementation is built or installed by this release, and no runtime capability is claimed. Development qualification continues independently. A future qualified runtime release must supersede this version and own the same PDF path.
